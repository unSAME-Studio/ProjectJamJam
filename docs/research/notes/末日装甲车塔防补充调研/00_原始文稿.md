# 末日装甲车塔防（暂名）— 设计文稿与调研

Nov 2, 2026 · @unSAME

## TL;DR

你一个人在自己拼起来的末日装甲车里来回跑：加煤、降温、开窗射击。杀丧尸攒金币，走到对应位置加模块或改装，车越开越像一座会跑的塔防要塞。车毁了就在车库买永久升级，再出发。

**核心幻想**：从手忙脚乱的锅炉工，变成运筹帷幄的车长。

**调研后的三条结论**

1. 单项机制都有先例，组合是空位。车内跑腿有 FAR、Lovers、Unrailed!，载具塔防有 Steam 上一批火车塔防，局外增量有 The Tower 和 Sir, We Have an Orc Problem。三者合一的，这次没找到。
2. 推荐侧视横截面。车内跑动和窗口射击最好读、成本最低，截图也能和俯视火车塔防分开。鸭科夫借调性和视野锥，不借镜头。
3. 设计核心是「注意力是资源」。新增模块加火力也加杂活，改装用效率或自动化把手腾出来。最大风险是杂活变苦差，第一个原型只验证这一点。

## 核心循环

&#91;embedded content: 核心循环 · 局内 4 步，局外 4 步\]

高亮的一步是和其他移动基地游戏最不一样的地方：强化要亲自跑过去，跑腿这段时间别的工位没人管。局内一局的目标长度是 15–25 分钟，见「局外增量结构」。

## 车内忙碌玩法

玩家的注意力是这款游戏的第一资源。每个模块都带来一件杂活，改装把杂活交给机器，新模块又带来新杂活：玩家永远有事做，但做的事越来越「高级」。

**设计规则**

- 一次只做一件事：手上只能拿一样东西（燃料、水桶、弹箱、扳手），车内跑动有真实距离。
- 仪表永远可见：压力、温度、弹量、车板耐久都挂在模块上，玩家能预判下一件要救的火。
- 放着不管会降级，不会立刻死：机枪卡壳几秒、车速掉到丧尸追得上、车板破洞。痛，但能救回来。
- 手动永远比自动好一点：手动加燃料能「超压」冲刺，手动射击能打弱点。自动化是为了腾出手，不是替代玩家。
- 同时需要盯的仪表目标 3–5 个（设计假设，原型验证）。

| 工位 | 手动杂活 | 不管会怎样 | 手动的甜头 | 自动化改装 |
| --- | --- | --- | --- | --- |
| 锅炉（动力） | 从燃料箱搬燃料丢进炉口 | 压力掉、车速掉，追兵贴上车尾 | 超压：短时冲刺甩开尸群 | 自动给料机 |
| 车顶机枪 | 过热前拉阀门浇冷却水 | 卡壳停火 | 红区前冷却，下一轮射速加成 | 自动喷淋 |
| 弹药 | 从压弹机搬弹箱到机枪 | 机枪空转 | 一次装满 | 传送带直送 |
| 射击窗 | 站到窗口亲自瞄准开火 | 那一面没人管 | 打弱点暴击，点掉精英怪 | 雇个枪手（NPC，准头差） |
| 车体维修 | 拿扳手补被啃破的车板、灭火 | 丧尸从破口钻进车里 | 修得快有短时护甲 | 自动焊机 |

**忙碌曲线**：开局 2 个工位、全手动，手忙脚乱；中期 3–5 个工位、自动化 1–2 个；后期大部分自动，玩家变成「救火队员 + 狙击手」。情绪弧线是从锅炉工当到车长。

**加压事件**：爬进车内的丧尸（玩家近战处理）、车板起火、爆胎。用来在平稳期打断节奏，逼玩家重新排优先级。

**操作**：WASD 移动，E 拿起/放下/交互，站在射击窗前鼠标瞄准、左键开火。射击时不能干杂活，「去开枪还是去加煤」就是核心决策。

## 模块与改装

两条成长线对应两种花钱方式：新增模块买「火力」，同时买来新杂活；模块改装买「解放」。每次花钱都在「更强」和「更省心」之间选。

**规则**

1. 新增：走到空槽位，从已解锁的模块池里随机给 3 个选 1。价格随车上模块数递增。池子由局外解锁决定。
2. 改装：走到模块旁长按，每模块 3 级。第一次改装选分支，之后只能沿这条线升：
   - 效率线：产出更高，仍然要人照看。
   - 自动化线：产出略低，但不再需要人。第 3 级给一个质变效果。
3. 强化要花时间：长按约 1.5 秒（占位）。这段时间别的工位没人管，强化本身也是一次注意力决策。
4. 扩建车体：买挂车或加层 = 新槽位。代价是车变长、跑得更远，反过来逼你自动化。
5. 相邻加成：模块挜在一起会产生联动，这是「搭基建」的深度来源。例：绞肉机贴着锅炉，丧尸就是燃料。

**示例模块**（数值均为占位）

| 模块 | 槽位 | 作用 | 效率线 | 自动化线 |
| --- | --- | --- | --- | --- |
| 锅炉 | 车厢内 | 提供动力，决定车速 | 大炉膛：一份燃料顶两份 | 自动给料机 |
| 车顶机枪 | 车顶 | 自动打最近的丧尸，会过热 | 水冷套：过热阈值 +50% | 自动喷淋 |
| 射击窗 | 侧窗 | 玩家手动射击 | 扩口：射角更大，可换霰弹 | 雇个枪手 |
| 撞角 | 车头 | 碾开拦路丧尸 | 锯齿撞角：碾压伤害 ×2 | 绞肉机：尸体自动变燃料 |
| 地雷投放器 | 车尾 | 炸后方追兵 | 双联投放 | 定时自动投放 |
| 电网 | 车身 | 电爬车的丧尸 | 高压电容 | 接锅炉余热自动充电 |
| 广场舞音箱 | 车顶 | 把丧尸吸到一侧扎堆（控场） | 低音炮：范围更大 | 单曲循环 |
| 金币磁铁 | 车顶 | 吸车外的金币 | 范围更大 | 常开 |

命名和文案沿用「涌现出来了！」的干净荒诞、一本正经的口吻：功能是严肃的，物件是离谱的。

## 塔防与基建

塔防的「地图」就是你的车：摆放是车体布局问题，路线和丧尸类型决定压力从哪一面来。车速本身也是一道防线。

**槽位区**：车头（拦路的）、车顶（覆盖广，怕爬车的）、两侧窗（侧面）、车尾（追兵）、车厢内（动力和生产，不直接打）。一个槽位放什么，等于塔防里「这个路口造什么塔」。

**一局的结构**：若干路段，每段 = 行驶 + 停靠。

- 行驶段：持续压力。追兵、拦路、爬车轮流来；锅炉没人管、车速掉下来，尸群就追上。
- 停靠段：加油站、路障、开吨桥。车停下，守住倒计时，丧尸从四面来，是经典波次塔防。
- 岔路选线：高速（安全、钱少）或城区（尸多、钱多、停靠多）。这是增量游戏的风险收益旋钮。

**丧尸类型：每种都逼你照顾一个槽位区**

| 丧尸 | 从哪来 | 逼你做什么 |
| --- | --- | --- |
| 普通尸 | 车尾追 | 保持车速，或车尾放火力 |
| 跑尸 | 车尾快追 | 锅炉超压、地雷 |
| 拦路胖子 | 车前 | 撞角、前向火力，或停车硬打 |
| 爬车尸 | 侧面爬上车顶 | 电网，或玩家亲自清 |
| 自爆尸 | 侧面 | 炸破车板，制造维修杂活 |
| 尸潮 | 停靠时四面 | 全车布局的期末考试 |

**下车基建（可选，第二阶段）**：停靠时玩家可以下车，在车外摆一次性的路障和炮塔，开走就丢。先做车上塔防，确认好玩再加。

## 局外增量结构

局外是标准增量：每次车毁都按里程和击杀结算零件，在车库里走到工位买永久升级。目标是每一局都比上一局开得更远一点。

**货币（不超过 3 种）**

| 货币 | 怎么来 | 用在哪 | 车毁后 |
| --- | --- | --- | --- |
| 金币 | 杀丧尸掉落 | 局内新增、改装模块 | 清零，按比例折成零件 |
| 零件 | 里程 + 击杀结算 | 车库永久升级 | 保留 |
| 蓝图 | 路段 Boss、里程里程碑 | 解锁新模块、新车型、新路线 | 保留 |

**车库（局外 Hub）**：和局内一样，走到对应工位才能买。

- 车体工位：车板耐久、初始槽位数、开局自带挂车。
- 船员工位：跑速、一次搬几个、开局雇一个 NPC。
- 军火工位：基础伤害、射速、暴击。
- 经济工位：金币加成、开局金币、金币折零件的比例。
- 图纸工位：花蓝图把新模块放进局内池子。

**节奏目标**（设计假设，原型后调）

1. 第一局 5–8 分钟车毁，死完立刻买得起 2–3 个升级。
2. 前 3 局每局至少解锁一样「能看见的新东西」（新模块、新丧尸、新路段），不只是数字。
3. 成熟的一局 15–25 分钟。
4. 每个地区终点一场尸潮 Boss，打过解锁下一地区：敌人数值跳一档，零件倍率也提高。这是软重置，用来打破增量的中期疲软。

**数字曲线**：丧尸血量按里程指数增长；玩家输出 = 模块数 × 改装等级 × 局外乘区。飘出来的大数字和越来越大的尸潮就是增量的爽点。

**坑**：参考 Sir, We Have an Orc Problem 收到的批评，升级树看着深、实际只是堆数值，玩家会很快发现。局外要多解锁新玩法，少堆百分比。

## 视角与美术

推荐原型先做侧视横截面。车内跑动、窗口射击、加层扩建在侧视下一眼就能看懂，成本也最低。鸭科夫借它的调性和视野锥，不借镜头。

| 维度 | 侧视横截面（推荐） | 俯视（鸭科夫式 3D 斜俯视） |
| --- | --- | --- |
| 车内跑动 | 楼层加梯子，跑腿距离看得见 | 要掀掉车顶，车内和车外抢屏幕，镜头一拉远角色就小 |
| 窗口射击 | 窗外就是丧尸来的方向 | 每扇窗一个视野锥，很好看 |
| 塔防深度 | 来敌收敛到前、后、顶、侧，像竖着的「植物大战僵尸」；深度要靠敌种和楼层撑 | 四面来敌，摆放谜题更深 |
| 扩建表现 | 加挂车、加层，像搭玩具屋 | 网格拼装（Cosmoteer 式） |
| 美术成本 | 2D 就够 | 3D 资产加镜头调试 |
| 差异化 | 「剖面里有人在跑」，一张截图就和俯视火车塔防分开 | 和 Steam 上一批俯视火车塔防撞脸 |
| 先例 | FAR: Lone Sails、The Final Station、Monster Train、Dead Ahead、Earn to Die | 逃离鸭科夫、Unrailed!、FTL、Cosmoteer |

侧视的代价是来敌方向少，车太长要横向滚屏。原型如果证明塔防太薄，再转俯视。

**「干净荒诞」的落地**

- 干净：纯色块、少纹理；信息全挂在模块上（压力表、温度计、弹量条），屏幕边缘少放 HUD。
- 荒诞：一本正经的末日配离谱的物件，比如广场舞音箱、用丧尸烧的锅炉、车顶晒衣杆。
- 丧尸偏蠢萌而不恶心，鸭科夫就是「严肃题材 + 可爱形象」的反差喜剧。
- 从鸭科夫借视野锥：每扇射击窗画出射角扇形，玩家一眼看出「哪一面没人守」。

## 品类调研

三个品类都印证了同一件事：「先手动、再自动化」本身就是成长的快感。但「喂锅炉、尸体当燃料」已经被 Roblox 的 Dead Rails 做过，我们的差异要落在模块塔防和局外增量上。

### Roblox：增量丧尸塔防与「载具即基地」

| 作品 | 核心循环 | 对我们的启发 |
| --- | --- | --- |
| Dead Rails（RCM Games，2025） | 多人坐火车穿越僵尸西部，一路喂锅炉，停站搜刮换钱 | 燃料就是计时器，尸体也能塞进锅炉；焊上车的东西有重量、会拖慢加速；局外货币买职业和车型 |
| A Dusty Trip（2024） | 沙漠公路上用捡来的零件拼车，管燃料、食物、水、机油 | 零件要亲手搬上车装好；散热器就是过热管理；攒废料换新车 |
| Build and Kill Zombies | 抽零件拼车冲进尸群，开到没油，按距离和击杀结算 | 一局就是一次出车，距离是最清楚的结算指标；武器装车头才先撞到丧尸 |

| Toilet Tower Defense / Anime Defenders | 梗图或动漫塔防，开箱抽单位 | 说明 Roblox 主流塔防已走向抽卡收集。开箱、交易、付费倍率都不抄 |

| The Tower – Idle Tower Defense（Tech Tree Games，2021，手游） | 一座塔，局内 Cash 升级，局外 Workshop 和实时研究 | 研究解锁「局内自动升级」；难度 Tier + 金币倍率跨过中段。计时墙和付费加速被骂 |
| Thronefall（Grizzly Games，2024） | 白天站到建筑上一键建造，夜里英雄守城 | 极简建造、干净美术；每局带 5 个 Perk。差评是总用同一套 |
| Bloons TD 6（Ninja Kiwi，2018） | 每座塔 3 条升级路线 × 5 级，高阶路线互斥 | 互斥分支形成构筑身份，直接对应效率线/自动化线 |
| Mindustry（Anuke，2019） | 炮塔靠传送带供弹，接冷却液提射速 | 和「给机枪降温」同构；从手动采矿到物流自动化 |
| The Gnorp Apologue / Nodebuster | 先自己敲石头再雇人自动化 / 短局 + Boss 开新层 | 增量的标准节奏；共同差评是后期偏刷 |
| The Perfect Tower II（2025-11 正式版） | 增量 + 塔防，几乎一切都能用 AI 自动化 | 自动化本身可以是玩法 |

这些作品的共识：

1. 局外只给起步优势，不替代局内成长。
2. 自动化要赚来，用来腾出注意力做更高阶的手动操作。
3. 高阶分支互斥。BTD6 允许两条线都点到中级、只有一条到顶，比我们现在「一选定终身」更宽松，可以原型里对比。
4. 用难度层 + 倍率跨过无聊中段，而不是一味加数值。
5. 局要短，下一个目标始终显示在屏幕上。单局普遍在 30 分钟以内。

### 移动基地

| 作品 | 核心循环 | 对我们的启发 |
| --- | --- | --- |
| Unrailed!（Indoor Astronaut，2020） | 火车不停，玩家砍树挖矿铺轨，还要给发动机浇水降温 | 最接近我们的杂活；车厢升级把杂活自动化；靠多人混乱撑住 |
| The Final Station（Do My Best，2016） | 停站横版射击，开车时在车厢里修系统、供电 | 镜头和「开车管理、停车战斗」的分段最接近我们；车内内容偏薄 |
| FTL（Subset Games，2012） | 船员进舱室给加成，反应堆电量在系统间分配 | 能暂停，所以忙而不乱；电力分配是简单清楚的取舍 |
| Cosmoteer（Walternate Realities） | 网格拼船，船员真的搬弹药和电池 | 布局决定跑腿距离：早期自己跑，成长就是让自己不用跑 |
| Last Train Home（Ashborne，2023） | 装甲列车，行驶时派人到车厢岗位，停车打 RTS | 分段清楚；但两套镜头两套系统，成本翻倍，我们要避免 |
| Monster Train（Shiny Shoe，2020） | 三层楼当车道守火堆 | 楼层就是车道，正好用在侧视车厢 |
| Dead Ahead: Zombie Warfare / Earn to Die | 侧视，巴士当基地出兵 / 开车冲尸群，死了升级再冲 | 证明「侧视 + 死后增量」在手机上成立；都没有车内这一层 |
| Guns of Icarus | 多人飞艇，工程师走到部件前按键修 | 「走到模块前」的原型；靠 PvP 压力撑住 |

要简化的是驾驶：让车自己往前开（像 Unrailed! 和 Dead Rails），玩家只通过锅炉管车速，全程一个镜头。

## 风险、开放问题与原型计划

最大的风险是杂活变苦差。原型要先回答「一个人在车里手忙脚乱好不好玩」，回答之前不做局外。

| 风险 | 早期迹象 | 对策 |
| --- | --- | --- |
| 杂活变苦差 | 测试者说「又要去加煤」 | 每件杂活都有技巧上限（超压、完美冷却）；第一个自动化在第一局内就买得到；杂活必须和射击抢时间 |
| 自动化把核心掐空 | 后期玩家站着不动 | 新模块持续带来新手动活；手动始终比自动强一点 |
| 塔防太薄 | 每局摆法都一样 | 敌人分方向逼你照顾不同槽位；相邻加成；岔路选线；仍不够就转俯视 |
| 增量中期疲软 | 几局之后只剩刷零件 | 地区软重置；蓝图解锁新玩法，而不是百分比 |
| 品类撞车 | 截图看起来像又一个火车塔防 | 一张截图就要看到「剖面里有人在跑」 |
| 范围膨胀 | 想同时做驾驶、下车、车外建造 | 车自己开；下车基建放第二阶段；只用一个镜头 |

**开放问题**

- 单人还是合作？Lovers、Unrailed! 和 Dead Rails 都靠多人撑住混乱，单人要靠自动化控制忙碌上限。
- 平台做 PC（Steam）、手机，还是直接做 Roblox？Roblox 上已经有同类爆款和现成受众。
- 一局有终点，还是无尽开到车毁？
- 金币自动吸入，还是捡钱也算一件杂活？
- 改装分支一选定终身，还是 BTD6 式「两条中级、一条到顶」？

**原型计划**（灰盒，沿用现在的 Godot 4 管线）

原型 1：手忙脚乱好不好玩

- [ ] 侧视横截面的车：2 层、约 4 个槽位，车自己往前开
- [ ] 3 个工位：锅炉、车顶机枪、射击窗
- [ ] 2 种丧尸：车尾追的普通尸、爬车尸
- [ ] 金币掉落；每个工位一条效率改装、一条自动化改装
- [ ] 车毁 → 结算 → 1 个永久升级 → 再出发
- [ ] 建议通过标准：多数测试者主动开第二局，并能说出「我先自动化了哪个、为什么」

原型 2：塔防深度

- [ ] 停靠波次；加上车头、车尾槽位区
- [ ] 2 组相邻加成
- [ ] 岔路选线

原型 3：增量骨架

- [ ] 车库 Hub，走到工位购买
- [ ] 第一个地区 Boss 与软重置
- [ ] 数值曲线表
