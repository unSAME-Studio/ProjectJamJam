# 01 · 核心交互：吐纳

> **⚠ 部分过时（原型阶段决定）**：去掉了「纳」——没有肚子，也没有肚子里的坍缩。现在的动词是**按住吸（拉到面前）、松开推（甩出去）**，所有坍缩都发生在世界里。本文关于「吸 / 吐」手感、身体、调参思路的部分仍可参考；实际实现见 `scripts/player.gd` 和 `docs/HANDOFF.md`。

> 一句话：**按住吸，松开吐。吸进去什么，就涌现出什么；吸够一样东西，它就在你肚子里变成更高级的东西。**

---

## 1. 问题：v1 的交互缺了什么

v1 的动作是"按住蓄力 → 松开喷射"。它有笑点（「力量——涌现出来了！」），但拿块魂一对比就露馅：

| 块魂的一个动词「滚」同时做了 | v1 的「喷」做到了吗 |
|---|---|
| 移动 | ✗ 移动是另一个输入 |
| 收集 | ✗ 喷只会让东西变多 |
| 成长（越大能滚越大的东西） | ✗ 没有成长 |
| 推进进度 | ✗ 主进度是坍缩，但坍缩是世界自己发生的，玩家没法主动促成 |
| 清理世界 | ✗ 世界只会越来越满，减法全靠系统兜底 |

结论：v1 的玩家是一个**开关**。世界在涌现，玩家只是点火。

---

## 2. 候选动词

| 候选 | 描述 | 优点 | 问题 |
|---|---|---|---|
| A. 喷射 | v1 现状：蓄力 → 锥形冲击 | 喊叫节拍完整；实现最便宜 | 上面那张表全 ✗ |
| B. 碰撞 | 玩家把自己当炮弹撞出去 | 物理感强，像山羊 | 丢了丹田梗；仍然没有收集和成长 |
| C. 爆炸 | 蓄力 → 原地径向爆开 | 场面大 | 没有方向；第三次就腻；也没有收集 |
| **D. 吐纳** | **按住 = 吸，松开 = 吐** | 一个输入同时覆盖：收集、成长、主动坍缩、清理、喷射；A/B/C 都变成它的子集 | 比 A 多一套"吸"的手感要调 |

**选 D。** 它不是第四个选项，而是把前三个装进了一个循环：

```
         按住                         松开                      撞上别的东西          吸太多
  吸 ─────────────→ 丹田里堆着东西 ─────────────→ 喷射(A) ─────────────→ 碰撞(B)      爆炸(C)
  │                    │
  │                    └─ 同类够数 → 在肚子里坍缩成更高级的东西（玩家主动推进进度）
  └─ 吸走 = 世界里少了这些东西（玩家本身就是垃圾回收）
```

而且它跟气功是一回事：**吐纳**。不用解释。

## 3. 规则

### 3.1 输入

| 输入 | 键鼠 | 手柄 |
|---|---|---|
| 移动 | WASD | 左摇杆 |
| 镜头 | 鼠标 | 右摇杆 |
| **吐纳** | **按住 / 松开 空格或左键** | **按住 / 松开 RT** |

没有别的键。方向 = 角色朝向（吸和吐都朝前）。

### 3.2 吸（按住）

- 角色扎马步，镜头推近，喊「力量——」，**音调随肚子里的东西变多往上走**
- 前方一个锥形范围（半径和角度随身体成长变大）里，**松散的、尺寸够得着的**物体被拉过来，缩小，钻进丹田
- 肚子肉眼可见地鼓起来；头顶一排 QQ 表情大小的图标显示肚子里有什么（`🕊×12 💰×7`）
- **固定物体**（ATM、树、消防栓……）吸不动，但会被吸得摇晃，持续吸 ~1 秒 → 它涌现，涌出来的东西顺着气流飞进你肚子。**按住对着 ATM 就是在"榨"它**
- 等身体长得够大，原来吸不动的固定物体也可以**连根吸走**。块魂那一刻：前面你在榨 ATM，后面你把 ATM 整个吞了

### 3.3 肚子里的坍缩

- 丹田里同一种东西数量 ≥ `collapse_n` → **立刻在肚子里坍缩**：肚子一亮、一声 QQ 滴滴、彩虹字「资本涌现出来了。」
- 这是**玩家主动推进进度**的方式：想要更高级的东西，就去吸够一种东西
- 世界里的自然坍缩（东西自己堆在一起）仍然保留，但门槛更高（×1.5），作为 NPC 连锁的副产品

### 3.4 吐（松开）

- 「涌现出来了！！！」肚子里的所有东西朝前喷出，外加一股基础气流（水 / 气）
- 吸得越久、东西越多，喷得越远越猛（按住时长 + 内容物数量共同决定冲量）
- **空肚子也能吐**：只喷基础气流，等于 v1 的喷射。所以 A 方案完整保留
- 最短按住 0.3 秒，保证台词能喊完

### 3.5 碰撞（传播）

- 被吐出来的东西以超过阈值的速度撞上可涌现物体 → 对方涌现
- 碰撞配方：特定 A 撞 B → 特殊结果（钱 撞 路人 → 老板）
- 被涌现出来的东西继续乱飞、继续撞，这就是连锁

### 3.6 爆炸（过载）

- 每具身体有容量上限。接近上限：打嗝预警（「嗝。」+ 肚子发红闪）
- 超过还继续吸 → **丹田爆了**：所有内容物径向喷出，角色布娃娃飞出去，字幕「丹田涌现出来了。」
- 这不是惩罚，是一个可以**故意用**的大招：对着一群东西吸到爆，等于一颗手雷

### 3.7 传染（开窍）

- 路人被吸进丹田再吐出来，或被高速撞中 → 爬起来 → 沉默一秒 → 「原来如此。」→ **开窍**
- 开窍的 NPC 会自己做小规模吐纳：吸附近几个小东西，朝随机方向吐
- 开窍 NPC 也是小吸尘器：他们制造连锁，同时帮忙回收世界里的东西

### 3.8 成长

- 每次肚子里发生坍缩 → 丹田 +1 级：身体放大 ~10%、吸力半径和容量变大、能吸的尺寸上一档
- 每具身体 3 级。第一幕的满级时刻：你能把网吧整个吸进去
- 尺寸档位见内容表 `size` 列：S / M / L / XL，按**本幕身体**的相对大小算

## 4. 同一个输入，四具身体（What The Golf）

吐纳在每具身体上的意思不一样，但按键永远一样：

| 身体 | 出现在 | 吸（按住） | 吐（松开） | 爆（过载） | 成长表现 |
|---|---|---|---|---|---|
| 气功小人 | 第一幕 | 扎马步吸气，肚子鼓起 | 丹田喷射 | 原地炸开，布娃娃 | 肚子 / 体型变大 |
| **鼠标指针** | 桌面插曲 | 按住 = 蓝色半透明框选，图标吸附成一摞跟着指针 | 松开 = 拖拽甩出去 | 「程序未响应」，指针转沙漏，图标散一地 | 指针变大、拖影变长 |
| 挖掘机 | 第二幕 | 挖斗下沉铲起，斗里堆满 | 甩斗 | 翻车 | 挖斗变大 |
| 地球 | 第三幕 | 引力：卫星、月亮、文明绕着转 | 抛射 | 轨道崩溃，绕转物全部甩飞 | 半径变大，像块魂 |

身体切换的引导：新身体永远是上一段里**由玩家自己吐出来**的东西（见 `02_结构与插曲.md`）。

保底：如果到 D5 身体切换做不完，三幕都是小人，只换镜头和尺度。吐纳规则不依赖身体。

## 5. 镜头

- 第三人称跟随，可旋转，默认偏俯视 35°
- 按住时推近（节拍感），松开回弹 + 轻微震屏，震屏强度 = 喷出物数量
- 场面变大（活跃物体数 / 连锁半径）→ 镜头自动拉远
- 身体成长 → 默认镜头距离同比拉远（块魂式：你变大，世界变小）

## 7. 原型必须回答的问题

1. **吸本身爽不爽？** 东西被拉过来、缩小、钻进肚子那一下，要有块魂"啪嗒"粘上的满足感。不爽就回退到 A 方案（纯喷射），其它系统不受影响
2. **吐出"有内容"的东西，比空吐好玩多少？** 如果差不多，说明内容物的碰撞配方不够
3. **肚子里的坍缩看得懂吗？** 玩家能不能自己意识到"吸够 20 张钱会变资本"
4. **榨固定物体直觉吗？** 第一次对着 ATM 按住，玩家是否会等到它吐钱
5. **爆炸是彩蛋还是烦人？** 如果玩家频繁误爆，调高容量或者去掉过载
6. **玩家的吸能不能把物体数量控制住？** 理想状态是不需要假蓝屏兜底，玩家自己就是垃圾回收
