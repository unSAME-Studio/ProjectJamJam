# 一周计划（4 人 · 7 天）

目标：10–15 分钟完整弧线，第一幕扎实，二三幕可以短。
**第 3 天结束必须有人能从头玩到第一幕结束并笑出来**，否则二三幕全砍。

## 分工

| 人 | 主责 | AI 用在哪 |
|---|---|---|
| P1 程序 · 核心 | `EmergenceDef` / 触发 / 碰撞配方 / 坍缩 / 传染 / CSV 导入 | 代码生成、Godot 文档查询 |
| P2 程序 · 表现 | 镜头 / 玩家身体 ×3 / VFX / 假蓝屏 / 插曲 A–C / UI 碎片 | shader、UI 原型 |
| P3 美术 | 低多边形道具 ~40 件、三具身体、街区 / 城市 / 太空 三个场景 | 文生 3D 打底 → 手修统一；贴图、招牌文字生成 |
| P4 设计 · 音频 | `emergence_table.csv` 内容与平衡、文案、配音、SFX、BGM、打包页面 | AI 配音、文案变体、音效生成 |

## 排期

| 天 | 里程碑 | 具体 |
|---|---|---|
| D1 | **灰盒能喷** | 小人移动 + 按住松开喷水；5 个灰盒物体（ATM / 树 / 消防栓 / 鸽子 / 路人）各一个 emits；CSV 导入跑通 |
| D2 | **连锁成立** | 物体撞物体触发；坍缩（钱→资本、鸽子→鸽群）；传染（路人学会涌现）；系统通报弹窗 |
| D3 | **第一幕可玩** ★ | 第一幕全部 approved 物体进引擎（灰盒也行）；插曲 A（Logo 被喷出来、UI 碎片飞上屏幕）；镜头自动拉远。**全员试玩，决定二三幕规模** |
| D4 | 第二幕 | 挖掘机身体；尺度跃迁（第一幕烘焙成地砖）；插曲 B 连发系统 + 假蓝屏；第二幕物体进引擎 |
| D5 | 第三幕 + 终幕 | 地球身体（滚动）；插曲 C 网吧拉远镜头；第三幕物体；「涌现」终幕 + 名单 + 回冷开场。**砍身体切换的最后期限** |
| D6 | 磨 | 配音替换 AI 占位、音效全覆盖、彩虹字幕、性能上限与归档、全流程 3 次试玩修平衡 |
| D7 | 交 | 打包（Win + Web 如果性能允许）、截图、GIF、itch 页面文案、提交。下午不加功能 |

## 砍单（按顺序砍）

1. 第三幕缩成 60 秒过场（地球不可操作，直接演坍缩 → 终幕）
2. 身体切换 → 三幕都是小人
3. 第二幕物体减到 6 个
4. 消化者只留下水道和垃圾车
5. 插曲 B 只留 3 个系统
6. 归档 UI 不做，靠假蓝屏兜底

## 不砍

- 按住松开 + 「力量——涌现出来了！」
- 碰撞触发 + 坍缩 + 传染
- 插曲 A（游戏涌现出来了）
- 终幕递归
- 千禧年 UI 语气（弹窗通报 + 蓝屏）
