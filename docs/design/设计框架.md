## 0. 已锁定的决策

| 项 | 决定 | 备注 |
|---|---|---|
| 维度 | **3D**，等距偏俯视、可旋转的第三人称 | 要块魂 / 模拟山羊那种一堆东西乱飞的混乱感 |

## 1. 核心交互

### 1.1 唯一的输入

```
按住  →  扎马步 / 蓄力，镜头推近，「力量——」
松开  →  「涌现出来了！！！」丹田方向喷出冲击
方向  →  摇杆 / 鼠标
力度  →  按住时长（0.3s 最小，保证台词喊完）
```

从头到尾玩家只有这一个动作（+ 移动）。整个游戏的"进度"不是解锁新按键，而是**这个按键作用在越来越离谱的东西上**。

### 1.2 What The Golf 模式：同一个输入，三具身体

| 幕 | 身体 | 按住做什么 | 松开喷什么 | 移动是什么 |
|---|---|---|---|---|
| 一 · 街道 | 气功小人 | 扎马步 | 水 / 气 | 走路 |
| 二 · 城市 | **挖掘机** | 挖斗抬起、引擎轰鸣 | 一斗子的东西（人、车、钱、楼）朝前甩 | 履带开 |
| 三 · 宇宙 | **地球** | 自转加速 | 文明 / 卫星 / 概念 | 像块魂一样滚 |

- 挖掘机是千禧年梗（"挖掘机技术哪家强"），同时是最适合城市尺度的物理载具：会撞、会铲、会甩
- 地球滚动 = 块魂，它本身就是尺度跃迁的玩具化
- 换身体的"引导合理"：**玩家的新身体一定是上一幕由玩家自己坍缩出来的那个最大的东西**。玩家看着它涌现出来，镜头拉远，下一秒就在操作它。不解释，直接给
- 保底方案：三幕都是小人，只换镜头距离和喷射物。身体换装只影响 `PlayerBody` 这一层，核心逻辑不依赖它，所以可以到第 5 天再决定砍不砍

### 1.3 连锁靠物理，不靠脚本

1. 玩家冲击打中 → 触发该物体涌现
2. 任何物体**以足够速度撞上**另一个可涌现物体 → 也触发。喷出来的东西就是下一发子弹
3. **碰撞配方**（稀疏、可猜）：特定 A 撞 B → 特殊结果。无配方则回落到 B 自己的涌现
4. **传染**：NPC 被打中 → 爬起来 → 沉默一秒 → 「原来如此。」→ 他也会涌现了，开始自己乱喷

传染是连锁的引擎，也是为什么后面镜头可以不跟玩家：满街都在喷，你不特殊了。

### 1.4 镜头

- 距离 = f(活跃物体数, 场面半径)，自动拉远，玩家不用管
- 按住时推近（节拍），松开回弹
- 拉远到阈值 → 尺度跃迁（§2.4）→ 换身体

## 2. 消化：每一次减少本身也是一次涌现

原则不变：**不能偷偷删东西**，所有减法都要带大字幕。

| 阀门 | 触发 | 效果 | 解决什么 |
|---|---|---|---|
| **坍缩**（主） | 同类 ≥ N 个聚在一起 | 合成一个 +1 层的东西 | 数量、尺度、笑点、进度——四合一 |
| **消化者** | 特定物体吃特定物体 | 吃够了涌现别的 | 局部清理（下水道吃水 → 鳄鱼） |
| **归档** | 太远 / 太久不动 | 飞进屏幕角的「回收站」+1 | 小垃圾清理。回收站本身是垃圾车吃够垃圾山之后涌现出来的 UI |
| **尺度跃迁**（硬） | 镜头拉远到阈值 | 上一幕全部烘成贴图，变成新幕的地面 | 跨幕清零 |
| **假蓝屏**（兜底） | 逼近物理上限 | 「系统错误：涌现过多」→ XP 蓝屏 → "重启"进入下一幕 | 性能兜底 = 笑点 |

**坍缩是唯一的进度来源。** 没有任务，没有计数器。你把东西堆到一起，世界就升级。

## 3. 结构：三幕 + 四个插曲

```
[冷开场] 黑屏，拨号上网声。一个灰色小人站在灰色街道上。没有 UI
   ↓ 第一次按住松开
[插曲 A]「游戏涌现出来了」
   喷出来的第一个东西是游戏 Logo，带物理掉在地上。
   接着：Flash 风格 Loading 条、分数、小地图……
   每个 UI 都是从某个物体里喷出来再飞到屏幕上贴好的
   ↓
[第一幕 · 街道]  小人。物体 → 生物 → 小机构
   ↓ 坍缩积累，镜头拉远
[插曲 B]「系统涌现出来了」
   连发半成品系统，每个活 3 秒：任务 / 血条 / 升级 / 合成 / 魂类「涌现已失去」
   它们互相坍缩 → 一个叫「游戏性」的物体 → 砸进城市 → 假蓝屏 → 重启
   ↓
[第二幕 · 城市]  挖掘机。机构 → 经济 → 互联网
   ↓ 镜头继续拉远
[插曲 C]「GAME JAM 涌现出来了」
   拉远：整座城市原来是网吧里一台显示器。包夜的四个人，屏幕上写着
   Theme: EMERGENCE。他们在做的就是这个游戏。再拉远，网吧在地球上
   ↓
[第三幕 · 宇宙]  地球。文明 → 概念 → 一切
   ↓
[终幕]「涌现涌现出来了！」
   一切坍缩成一个巨大的实体文字「涌现」。
   对它喷 → 喷出制作人员名单（物理的）→ 名单砸中一个灰色小人 → 回到冷开场
```

Meta 的分寸：主体时间都在玩物理连锁，插曲只占节拍点，每个 ≤ 30 秒。所有系统字幕保持平静通报体。

## 4. 语气：中文千禧年互联网

不是"复古像素"，是 **2003–2010 的中文互联网 + 电脑城 + 网吧**。认真、朴素、荒唐。

### 4.1 视觉与 UI

| 元素 | 做法 |
|---|---|
| 系统字幕 | XP 风格弹窗：`系统提示 ×`　`钱涌现出来了。`　`[确定]` |
| 大字幕 | 彩虹渐变 + 描边 + 闪图 GIF 感，字体往华文彩云 / 华文琥珀方向 |
| UI 碎片 | 弹窗广告、桌面宠物（小狮子式）、右下角新闻弹窗、"您有新的消息" |
| 假崩溃 | XP 蓝屏，白字，"涌现过多，系统已停止响应" |
| Loading | Flash 小游戏站的 Loading 条 + "游戏加载中…请耐心等待" |
| 归档 UI | 屏幕角的「回收站」图标，东西飞进去 +1 |
| 世界 | 低多边形明亮玩具城，但招牌、小广告、横幅全是那个年代的字体和配色 |

### 4.2 文案

- 系统通报永远是：「XX 涌现出来了。」句号，不是感叹号。只有玩家角色喊的时候用感叹号
- NPC 台词往气功 / 本山 / 页游广告的方向：「原来如此。」「是兄弟就来涌现。」「走过路过不要错过。」
- 概念物体的名字直接用那个年代的词：网瘾、非主流、火星文、偷菜、3Q 大战、页游
- 不要解释笑点，不要吐槽，一切当真事办

### 4.3 声音

- 拨号上网声（冷开场）、XP 启动音（插曲 A）、QQ 滴滴声（每次涌现通报）、XP 错误音（假蓝屏）
- 配音：中文为主，AI 配音打底，关键几句找人真喊

### 4.4 边界

戏仿风格，不堆真实商标。"小狮子"不叫瑞星，"3Q 大战"叫"两个杀毒软件打起来了"。

## 5. 内容语法

### 5.1 数据定义（Godot Resource，从 CSV 生成）

```
EmergenceDef
  id, name, tier(1-6), act(1-3)
  pattern:       container | reproduce | concept | system | recursive
  emits:         喷什么 / 几个
  collapse_n:    几个聚一起坍缩
  collapse_into: 坍缩成什么
  eats / eat_emits: 吃什么 / 吃够了喷什么
  recipes:       被什么撞 → 变什么
  line:          通报字幕 / 台词
```

### 5.2 规则

- 产出只能是**同层或 +1 层**；坍缩永远 **+1 层**。尺度单调上升
- 每一幕 8–12 种物体，总计 30 种左右
- 每个物体回答两个问题：**"里面有什么"**（喷）和**"一堆它叫什么"**（坍缩）
- 所有物体先进 CSV，再进引擎。CSV 里 `status` 没到 `approved` 的不做资产

### 5.3 示例链

```
ATM ─喷→ 钱 ─×20→ 资本
钱 撞 路人 ─配方→ 老板 ─喷→ 上班族 ─×10→ 公司
公司 ─喷→ 电脑 ─喷→ 弹窗广告 ─×15→ 杀毒软件 ─×2→ 两个杀毒软件打起来了
电脑 ─喷→ 游戏 ─×5→ GAME JAM（插曲 C 的触发）
```

## 6. 技术备忘（Godot 4）

- 物理硬上限 ~300 RigidBody，超出走坍缩 / 归档 / 假蓝屏
- 坍缩检测：按 id 分桶，每 0.25s 做一次空间查询，不要每帧
- 尺度跃迁后旧物体转 MultiMesh，退出物理
- `PlayerBody` 是独立层：小人 / 挖掘机 / 地球 都实现同一个 `charge() / release(dir, power)` 接口
- CSV → `.tres` 用一个编辑器脚本一键生成，设计师不碰代码
- 美术全部低多边形 + 纯色，便于 AI 生成模型后统一风格
