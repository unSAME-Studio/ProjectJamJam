# 04 · 未来方向（记录，不在 jam 范围内）

> jam 版是一个 10–15 分钟的小体验。这里记录三个可能的长线方向，以及**现在就可以顺手留的接口**。
> 原则：现在不为它们写一行额外玩法代码，只在数据结构和命名上保持兼容。

---

## 方向 1 · 放置 / 挂机 / 增量

**想象**：玩家不断往一个"容器"里扔各种爽东西，它持续涌现、坍缩、升级，产出分数，可以离线挂机。

**现在已经指向它的东西**

- 吐纳本身就是"往里放东西 → 产出更高级的东西"，丹田就是那个容器
- 坍缩链天然是增量游戏的升级树（钱 → 资本 → 公司 → 经济）
- 连涌计数就是分数的雏形

**现在顺手留的接口**

- `EmergenceStats` 全局单例：记录每一次涌现、坍缩、吃、归档事件（id、时间、来源、数量）。原型里它服务于 `ActDirector` 和调试，将来直接就是增量游戏的产出账本
- 坍缩门槛 `collapse_n` 放在数据表里，不写死

**现在不做**：分数 UI、离线收益、升级商店。

---

## 方向 2 · AI 生成的涌现逻辑（无尽物体交互沙盒）

**想象**：任何东西都能涌现。玩家输入或世界里出现一个从没定义过的东西，AI 实时决定它涌现什么、一堆它叫什么、撞到别的会怎样。

**现在已经指向它的东西**

- 内容表的列就是一份**生成协议**：`emits / collapse_into / eats / recipes / line / tier / size`。AI 只需要输出一行这样的数据，不需要写代码
- 五种涌现语法（container / reproduce / concept / system / recursive）就是 prompt 里的"创作规则"
- "好像有点道理，但多疯了一步"就是给模型的风格指令

**现在顺手留的接口**

- 所有行为都是**参数化的通用行为**（喷、坍缩、吃、配方、开窍），不给单个物体写专属脚本。真需要特殊行为的，做成新的通用行为类型再在表里引用
- **未知物体兜底**：一个物体没有模型时，用它名字的彩虹 3D 实体字当模型（`03_视觉与字幕.md` §2.4）。这让 AI 生成的任何概念都能立刻出现在世界里
- 表里的名字引用都要能被校验（`tools/validate_table.py`），将来 AI 生成的行也走同一个校验

**现在不做**：任何运行时 LLM 调用。

---

## 方向 3 · 故事 / 关卡 / 目标（解谜 / 沙盒街机）

**想象**：不用很强的故事，但有节奏和挑战。每关一个目标：「涌现出 100 只鸽子」「只用 3 次吐纳把银行变成经济」。物理爽变成解谜 + 街机。What The Golf 的关卡感。

**现在已经指向它的东西**

- **桌面插曲**就是一个目标关卡的原型：明确目标（启动 exe）+ 阻碍（内存不足）+ 唯一手段（甩进回收站）
- 每一幕的结束条件都是可测量的状态（`02_结构与插曲.md` §3），换成"关卡目标"只是换文案
- 吐纳次数天然可计数 → "标准杆"：几次吐纳完成目标
- 碰撞配方的发现就是解谜

**现在顺手留的接口**

- `ActDirector` 的结束条件写成数据（监听哪个事件、阈值多少），不写死在脚本里
- `EmergenceStats` 记录吐纳次数

**可以在 jam 里试水的玩笑版**：企鹅消息弹出「帮我涌现 10 只鸽子，谢谢」，完成了回一个「嗯。」，没有奖励。

**现在不做**：关卡选择、星级评价、教程关。

---

## 三个方向的共同地基

```
内容表（数据） ──→ 通用行为（喷 / 吸 / 坍缩 / 吃 / 配方 / 开窍）
                         │
                         ↓
                  EmergenceStats（事件账本）
                    ├─→ ActDirector（jam：幕切换）
                    ├─→ 分数 / 挂机（方向 1）
                    ├─→ 关卡目标（方向 3）
                    └─→ 生成行校验与回放（方向 2）
```

jam 里只要把这个地基做干净，三个方向都不用推倒重来。
