# 02 · 结构与插曲

> 三幕 + 五段插曲，目标 10–15 分钟。新增：**蓝屏之后的电脑桌面插曲**（可玩，约 2 分钟）。

---

## 1. 总流程

```
[冷开场]            黑屏，拨号上网声。灰色小人站在灰色街道上。没有 UI
   ↓ 第一次吐纳
[插曲 A] 游戏涌现出来了         ~30s   演出 + 可玩
   ↓
[第一幕 · 街道]  小人            ~4 min  可玩
   ↓ 丹田满级
[插曲 B] 系统涌现出来了         ~40s   可玩
   ↓ 「游戏性」砸地
[蓝屏]                         ~5s    演出
   ↓ 按任意键
[桌面插曲] 内存不足             ~2 min  可玩（鼠标指针）
   ↓ 双击 .exe
[第二幕 · 城市]  挖掘机          ~3 min  可玩
   ↓ 镜头拉远到阈值
[插曲 C] GAME JAM 涌现出来了    ~30s   演出
   ↓
[第三幕 · 宇宙]  地球            ~2 min  可玩
   ↓ 一切坍缩
[终幕] 涌现涌现出来了！         ~1 min  可玩 + 演出
   ↓
[冷开场]（循环）
```

---

## 2. 各段详情

### 冷开场

- 黑屏 2 秒，拨号上网的「嘀——嘟嘟嘟——沙沙沙」
- 淡入：灰白低模街道，灰色小人。没有 HUD、没有标题、没有提示
- 唯一提示：屏幕底部一行很小的灰字「按住 空格」，第一次按下后就消失

### 插曲 A · 游戏涌现出来了

- 玩家第一次吐纳，喷出来的第一个东西是**游戏 Logo**（3D 实体文字，带物理，掉在街上弹两下）
- 全屏彩虹闪字：**游戏涌现出来了。**
- XP 开机音。世界从灰色"上色"：以 Logo 落点为圆心，颜色一圈圈晕开
- 之后 UI 一块一块涌现，**每块都是从某个物体里吐出来、飞到屏幕上贴好的实体**：
  - 第一次吸 → 头顶的肚子图标栏涌现
  - 第一次坍缩 → 右上角「连涌」计数涌现
  - 第一次碰撞触发 → 右下角 QQ 风格通报弹窗涌现
- 这段告诉玩家唯一的规则：**连这个游戏也是涌现出来的**

### 第一幕 · 街道（小人）

- 一个街区：路口 + 网吧 + 小卖部 + 银行门口 + 公园一角
- 物体见内容表 `act = 1`
- 节奏：榨 ATM → 吸钱 → 坍缩资本 → 吐 → 连锁；开窍的路人越来越多
- **结束条件**：丹田满级（3 级）。满级那一下玩家通常已经能把网吧吸走了

### 插曲 B · 系统涌现出来了

- 满级瞬间，天上开始掉**系统碎片**（实体 UI 窗口）：
  - 任务窗口「收集 10 个苹果 0/10」
  - NPC 头上冒血条（然后没有任何用）
  - LEVEL UP 金色光柱
  - 合成界面
  - 魂类风格大字「涌现已失去」
- 每个落地后会对周围东西做它那个系统的事情（血条贴到人头上、任务窗口追着玩家跑），3 秒后失效
- 玩家把它们吸进肚子 → 5 个坍缩成**「游戏性」** → 吐出去 → 「游戏性」砸进地面 → 全屏卡顿 → 蓝屏
- 拿 feature creep 开玩笑：系统越加越多，最后游戏崩了

### 蓝屏

- XP 风格蓝屏，等宽白字：
  ```
  检测到问题，系统已停止响应以防止对您的计算机造成损害。

  EMERGENCE_OVERFLOW

  如果这是您第一次看到此停止错误屏幕，
  请重新启动计算机。如果此屏幕再次出现，
  说明涌现出来了。

  按任意键继续_
  ```
- 按任意键 → 重启 → XP 风格开机 Logo → 桌面

### 桌面插曲 · 内存不足（新）

**场景**：一块巨大的 XP 风格桌面平铺成地面（蓝天绿草风壁纸，不用真壁纸），图标是有厚度的 3D 方块，任务栏是地图边缘的一堵墙。镜头和第一幕一样是 3D 第三人称。

**身体**：鼠标指针（一个 3D 白色箭头）。吐纳 = 框选（吸）+ 拖拽甩出（吐）。见 `01_核心交互.md` §4。

**目标**（全游戏唯一一个明说的目标，算是"未来方向 3"的试水）：

1. 桌面中央有一个 **`涌现出来了_第二章.exe`**
2. 把任何东西甩到它身上 = 双击 → 弹窗「内存不足，请关闭一些程序。」
3. 任务栏右侧有一个内存条（任务管理器绿色柱子），已经快满
4. 桌面上的东西会**自己繁殖**：新建文件夹 → 新建文件夹 (2) → (3)……、QQ 消息滴滴滴、IE 弹窗
5. 唯一的减法：把东西甩进**回收站**。回收站吃够 → 它自己涌现：「清空回收站」的纸团声 → 内存条掉下去
6. 内存够了以后再砸 exe → Flash 风格 Loading 条「第二章加载中…请耐心等待」→ 第二幕

**为什么要有这段**：

- 把"垃圾回收"这件事字面化，跟把"涌现"字面化是同一个笑话的反面
- 第一次让玩家体验**同一个输入、换了身体**，为第二幕的挖掘机做铺垫
- 桌面后面会在插曲 C 里被揭晓：它就是网吧那台电脑

**桌面上的东西**（内容表 `act = D`）：

| 东西 | 涌现 | 备注 |
|---|---|---|
| 我的电脑 | 文件 | |
| 新建文件夹 | 新建文件夹 (2) | 繁殖。8 个坍缩成**压缩包** |
| 压缩包 | 解压 → 12 个新建文件夹 | 坍缩 = 压缩，涌现 = 解压。砸它是陷阱 |
| 扫雷 | 地雷 | 地雷被撞 → **爆炸**，桌面上唯一的范围爆炸 |
| 纸牌 | 52 张扑克牌 | 胜利瀑布动画，物理版 |
| 企鹅（聊天软件） | 消息 | 消息 ×10 → 群聊 → 更多消息。内存炸弹 |
| 浏览器 | 弹窗 | 复用第一幕的弹窗 |
| 播放器 | 音符 | 音符 = 声波，范围触发 |
| 记事本 | 字 | 字 ×8 → 字幕（彩虹实体字）。字幕被撞 → 散成字 |
| 桌面宠物 | — | 复用杀毒软件小狮子，追着弹窗吃 |
| 回收站 | — | 吃任何东西，吃够 → 清空 → 释放内存 |

### 第二幕 · 城市（挖掘机）

- Loading 条走完，镜头从一块屏幕里推出来：一座城市。玩家是一台挖掘机
- 挖掘机的出处：第一幕的最后，网吧被吸进肚子以后吐出来的是……（留给美术决定是否演，最便宜的办法是 Loading 条上写「挖掘机技术加载中」）
- 物体见内容表 `act = 2`
- **结束条件**：镜头拉远到阈值（世界里机构级物体坍缩出「经济 / 互联网」以后自然发生）

### 插曲 C · GAME JAM 涌现出来了

- 镜头继续拉远：城市原来是一台显示器里的画面
- 显示器在一家网吧里。包夜的四个人，屏幕边上贴着便利贴 `Theme: EMERGENCE`
- 旁边一台显示器上是刚才的桌面（桌面插曲回收）
- 四个人同时转头看镜头，沉默一秒：「原来如此。」
- 继续拉远：网吧 → 城市 → 地球。身体变成地球

### 第三幕 · 宇宙（地球）

- 像块魂一样滚，引力吸积月亮、卫星、太空垃圾
- 物体见内容表 `act = 3`
- 砍单第一项：如果来不及，这一幕变成 60 秒的演出，地球不可操作

### 终幕 · 涌现涌现出来了！

- 宇宙里所有东西最终坍缩成一个巨大的**实体文字「涌现」**（就是一个超大号的彩虹字幕）
- 地球（或者小人）对它吐纳 → 它吐出**制作人员名单**：每个名字是一个实体字幕，带物理
- 名单之一砸中街道上一个灰色小人 → 小人站起来，沉默一秒，「原来如此。」
- 黑屏，拨号上网声 → 冷开场（循环）

## 3. 每段的结束条件一览

| 段 | 结束条件 | 可测量 |
|---|---|---|
| 冷开场 | 第一次吐纳 | 输入事件 |
| 插曲 A | 演出结束（~30s） | 计时 |
| 第一幕 | 丹田 3 级 | 丹田等级 |
| 插曲 B | 「游戏性」被吐出并落地 | 物体 id 事件 |
| 蓝屏 | 按任意键 | 输入事件 |
| 桌面插曲 | 内存低于阈值 时 exe 被击中 | 内存值 + 碰撞事件 |
| 第二幕 | 「经济」或「互联网」出现 + 镜头距离阈值 | 物体 id + 镜头距离 |
| 插曲 C | 演出结束 | 计时 |
| 第三幕 | 「涌现」出现 | 物体 id |
| 终幕 | 名单击中小人 | 碰撞事件 |

全部挂在一个 `ActDirector` 上，监听 `EmergenceStats` 的事件即可，不需要任务系统。

## 4. 原型里已经能看到的尺度跃迁（v0.2）

原型没做插曲 B / 蓝屏 / 桌面，直接演示"镜头拉远 + 尺度换挡"这个过渡语法本身。

**推进方式**：顶部「涌现度」条（街道 260，城市 600）。你亲手造成的涌现 +（1 + 层级），被动连锁只算约 1/3，**第一次见到的东西 +6**，暴击 +3，坍缩 +2.5×层级，连涌有小加成。满了自动跃迁；地球只演一次，之后进度条停在"第三幕 未完待续"。调试键 **N** 直接跳下一段。

**涌现狂热（fever）**：连涌到 20 进入，至少持续 4 秒，连涌断了才退出。期间不再有慢动作 / 顿帧，屏幕边缘旋转彩虹（借 Love Spinnin' 的 RainbowOverlay 思路），视野变宽，移动 ×1.35，甩出速度 ×1.25，暴击率 +15%。

**身体**：进城市时身体换成挖掘机（就是那一刻涌现出来的东西），移动 ×1.9；按住时挖斗放下去铲，松开时一甩。

### 街道 → 城市（可玩）

| 时间 | 发生什么 |
|---|---|
| 0.0 s | 夺走操作；拉远开始（镜头距离 9 → 85，俯角 -28° → -58°，2.2 s） |
| 0.0 s | 街上所有松散物体**原地冻结**：上一幕的混乱变成一块静止的模型地台 |
| 0.7 s | 城市从地里长出来：道路网由近及远铺开，12 栋可涌现建筑（银行 / 公司 / 学校 / 工地 / 电视台 / 电脑城 / 网吧）+ 三圈天际线由近及远"弹"出地面，每栋带扬尘和低频轰隆 |
| 1.6 s | 全屏字幕「城市涌现出来了。」；玩家身体弹性放大到 3.5 倍 |
| 3.6 s | 镜头回落到新尺度下的正常距离（9 × 3.5） |
| 5.3 s | 交还操作；城市里撒一批 3.5 倍大的上班族、汽车、公交、钱 |

新尺度下规则不变：建筑可以榨，喷出来的东西继承发射者的尺度（巨型银行喷巨型钱，街上的小 ATM 还是喷小钱）。坍缩只在同尺度的东西之间发生。

### 城市 → 地球（预览，演完回到城市）

Powers of Ten 式的拉远：镜头高度按指数从当前高度升到 26 km（5 s），天空同步从蓝变成太空黑；城市变成球面上的一块方形地砖，旁边有月亮、星星和一圈彩虹环。「地球涌现出来了。」→「第三幕 未完待续。」→ 3 s 降回城市，继续玩。

正式版里这一段换成：插曲 C（网吧显示器拉远）→ 第三幕地球身体。
