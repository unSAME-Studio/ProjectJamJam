# 03 · 视觉与字幕

> 语气：**2003–2010 的中文互联网 + 电脑城 + 网吧**。认真、朴素、荒唐。
> 本文最重要的一节是 §2 彩虹动态字幕：它是这个游戏的"招牌视觉"，优先级等同于吐纳手感。

## 1. 总体视觉

| 层 | 做法 |
|---|---|

| 可选方向 | 往 Car Park Capital 的印刷感靠：粗黑描边（toon outline）、两阶色、纸纹叠层。跟千禧年海报不冲突，像同一张报纸的中缝广告。待看效果再定 |

## 2. 彩虹动态字幕（核心）

### 2.0 WordArt 字幕（已实现，v3）

一行，不换行，不贴底。参考：Office 97–2003 WordArt 的"波浪"形状 + 小红书土味海报的配色与粗描边。

| | 名字（如"城市"） | 后缀「涌现出来了。」 |
|---|---|---|
| 字体 | 思源黑体 Black + 程序加粗，**直角不圆边** | 同字体，0.62 倍大 |
| 颜色 | 海报色渐变沿名字横向铺开（4 套：热彩 / 粉蓝紫 / 红橙金 / 绿蓝，按名字随机），上亮下暗 | 纯黄 #ffe100 |
| 描边 | 白色内边 + 深紫粗外框（约 0.11 倍字高） | 只有深紫外框，按自己的字号算，不加白边 |
| 立体 | 深紫硬阴影，跟着字一起弯 | 同 |
| 形状 | 整行 WordArt 波浪包络：上下边是两条正弦曲线，字被夹在中间，**实时流动** | 同一条波浪 |

配色避开了柠檬黄、浅青这类在天空 / 草地上看不清的颜色。

实现（`scripts/wordart_line.gd`，三步）：
1. 平面字渲染进离屏视图一次：名字写红色通道，后缀写绿色通道
2. 合成着色器 `wordart_compose.gdshader` 也只跑一次：方形膨胀出白边和外框（直角），填渐变 / 纯色
3. 显示着色器 `wordart_warp.gdshader` 每帧跑：按列把字压进波浪的上下边之间，加硬阴影。每帧开销只是一次贴图采样

设计稿与参数对照：`tools/wordart_preview.py`（Python 出图，参数同名），样张场景 `scenes/wordart_specimen.tscn`（F6 看动态）。

### 2.1 为什么重要

- 涌现发生的那一下，玩家的眼睛在乱飞的物体里，**字幕是唯一能让人读懂"刚才发生了什么"的东西**
- 千禧年闪字 / QQ 空间 / 炫舞签名是这个时代最有辨识度的视觉
- 字幕也是信息过载的阀门：它决定玩家**注意到**哪些涌现（§2.5）

### 2.2 三级字幕

| 级别 | 用在 | 位置 | 样式 | 时长 |
|---|---|---|---|---|
| **L1 气泡** | tier 1–2 的普通涌现、NPC 台词 | 世界空间，物体头顶 | 白字黑描边，QQ 聊天气泡底框，弹出时 0→1.2→1 缩放 | 1.2 s |
| **L2 彩虹字** | 坍缩、tier 3–4 的涌现、碰撞配方 | 世界空间，大号，面向镜头 | 彩虹渐变 + 逐字波浪 + 双层描边 + 投影 + 冲击缩放 | 2 s，然后字落地变实体（§2.4） |
| **L3 全屏闪字** | tier 5–6、所有插曲标题、终幕 | 屏幕空间，居中占 60% 宽 | L2 全部效果 + 逐字依次砸下 + 8fps 颜色闪烁 + 星星粒子 + 震屏 | 2.5 s，独占 |

### 2.3 L2 / L3 的具体效果

逐字（每个汉字单独一个单位）：

| 效果 | 参数起点 |
|---|---|
| 彩虹渐变 | 色相沿字符序号偏移 + 随时间滚动，0.5 圈/秒，饱和度 0.9，亮度 1.0 |
| 波浪 | 每字上下正弦，振幅 0.15 字高，频率 2 Hz，相位按字序错开 |
| 描边 | 内层白描边 4px + 外层深紫描边 2px |
| 投影 | 右下偏移 4px，黑色 50% |
| 入场 | 每字依次弹入，间隔 40ms，缩放 0→1.3→1（回弹），随机旋转 ±8° 后归正 |
| 闪烁（仅 L3） | 每 125ms 整体色相跳一格，模仿 GIF 闪图 |
| 星星（仅 L3） | 字周围持续冒四角星粒子 |
| 震屏（仅 L3） | 入场时 0.2s，强度随 tier |

### 2.4 字是实体

- L2 字幕停留结束后，**每个字变成一个 3D 实体字块掉到地上**，可以被撞、被吸、被吐
- 这是全游戏的一条视觉主线：
  - 插曲 A 的 Logo 是实体字
  - 记事本涌现出「字」，字 ×8 坍缩成「字幕」
  - 终幕的「涌现」是最大的实体字幕
  - 制作人员名单是实体字幕
- 也是未来"AI 生成物体"的兜底表现：没有模型的东西，直接用它名字的彩虹 3D 字当模型（见 `04_未来方向.md`）
- 性能兜底：实体字算普通物体，计入物理上限；落地 5 秒不动自动归档到回收站

### 2.5 字幕交通管制（信息过载阀门）

连锁一大，每秒可能有几十次涌现。规则：

1. **合并**：同一种通报在 1 秒内重复 → 合成一条并计数，`钱涌现出来了。×17`
2. **限流**：屏幕上 L2 最多 3 条，超了只保留 tier 最高的
3. **L3 独占**：L3 出现时，所有 L1/L2 暂停新增
4. **距离过滤**：离镜头太远的 L1 不显示
5. **连涌计数**：1.5 秒窗口内的触发次数，右上角彩虹大数字「连涌 ×12！」。到 10 / 50 / 100 时升级成 L3「连涌 ×100！」

### 2.7 Godot 实现建议

| 需求 | 方案 |
|---|---|
| 屏幕空间彩虹 + 波浪 | `RichTextLabel` 自带 BBCode `[rainbow freq=… sat=… val=…]` 和 `[wave amp=… freq=…]`，**原型第一天就能用**；描边用主题 `outline_size` |
| 逐字入场 / 闪烁 | 自定义 `RichTextEffect`（GDScript），按 `char_fx.relative_index` 做延迟缩放 |
| 世界空间字幕 | L1：`Label3D`（billboard）；L2：`SubViewport` 里放 `RichTextLabel` → 贴到 billboard 的 `Sprite3D` 上 |
| 实体字 | Godot 自带 `TextMesh` 生成有厚度的 3D 字 → 挂 `RigidBody3D`；彩虹用一个按世界坐标算色相的 shader |

## 4. 文案

- 系统通报永远是：「XX 涌现出来了。」**句号**。只有玩家角色喊的时候用感叹号
- NPC 台词往气功 / 东北小品 / 页游广告方向：「原来如此。」「是兄弟就来涌现。」「走过路过不要错过。」「嗯。」
- 概念物体用那个年代的词：网瘾、非主流、火星文、偷菜、页游、压缩包、新建文件夹
- 不解释笑点，不吐槽，一切当真事办
